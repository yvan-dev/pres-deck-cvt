# US-017 - Design the demo framing and recap pattern

## Story

As a speaker, I want a designed intro, anchor, and recap pattern for the live demo, so that the demo supports the talk even when live conditions are imperfect.

## Acceptance Criteria

1. Given the live segment is part of the narrative rather than the product itself, when the framing pattern is defined, then it covers what the audience should watch, what counts as success, and how to recover if the demo is shortened.
2. Given the deck must remain understandable without live success, when the recap pattern is specified, then it identifies the key lessons that can be restated even after a partial demo.
3. Given the final section must stay visually coherent, when the pattern is reviewed, then it fits the same pacing and visual system as the rest of the deck.

## Notes

- This story makes the live segment resilient instead of risky.
